# Тестовые данные

В тестовых средах только синтетические данные. Копию продуктива не используем, потому что в ней ПДн получателей.

## Как создаём

* Фабрики данных в тестах создают заказы, получателей, точки, смены и операторов. Имена — библиотека Faker (`ru_RU`).
* Seed генератора фиксированный, поэтому каждый прогон даёт одинаковые данные.
* Каждый тест создаёт свои данные сам. В CI они удаляются вместе со средой, на stage — по префиксу прогона.
* Тестовые среды не подключены к продуктивным БД и Kafka.

## Правила

| Что | Как |
|---|---|
| ФИО | Faker, в фамилии пометка «Тест» |
| Телефон | `+7 000 XXX-XX-XX` (несуществующий код) |
| Номер заказа | `TEST-<прогон>-<номер>` |
| Точки | `MDM-T001`, `MDM-T002` |
| Операторы | Тестовые учётки `op-test-…` с нужными ролями |
| Карты | Тестовые карты песочницы или эмулятор |
| Суммы | В копейках, заданы в наборе |
| Документ получателя | Не создаём, в системе он не хранится |

## Наборы

| Набор | Сценарий | Что внутри |
|---|---|---|
| TD-01 | E2E-01 | Точка MDM-T001, заказ с НП 249000 копеек в ячейке B-14, получатель, оператор с открытой сменой, код в заглушке SMS |
| TD-02 | E2E-02 | Точка MDM-T002, 30 предоплаченных заказов и 1 с НП, оператор |
| TD-03 | E2E-03 | Смена на MDM-T001: 20 выдач с НП, 15 предоплаченных, 1 оплаченный заказ без подтверждения выдачи, старший смены |
| TD-04 | E2E-04 | Выданный и оплаченный заказ с НП, оператор и старший смены MDM-T001 |

Ещё нужны редкие случаи: сумма 1 копейка, срок хранения истекает сегодня, ячейка уже занята, незнакомый код банка.
