# Матрица зависимости от поставщиков (Vendor Lock-in)

Оценка рисков внешних зависимостей системы ПВЗ. 
**Формула:** Риск = Вероятность события × Цена выхода.

| Компонент / Поставщик | Тип | Глубина зависимости | Цена выхода | Вероятность негативного события | Альтернативы | Стратегия снижения риска | Риск |
|---|---|---|---|---|---|---|---|
| **Провайдер оплаты (Банк)** | SaaS / Внешний API | Низкая (спрятан за ACL) | Средняя (1-2 мес. разработки) | **Средняя** (рост комиссии, изменение API) | Несколько на рынке | ADR-006, свой формат данных внутри системы, таймауты | **Средний** |
| **ERP (1С / SAP)** | Legacy / Внутренняя | Очень высокая (диктует формат) | Высокая (бизнес-процессы) | **Высокая** (окна обслуживания, медленный отклик, пакеты) | Не наш выбор, навязано бизнесом | Асинхронный обмен, очередь на нашей стороне, не блокируем выдачу | **Принимаем** |
| **SMS-шлюз** | SaaS / Внешний API | Низкая (спрятан за ACL) | Низкая (1-2 недели) | **Средняя** (рост цены, падение доставки) | Много на рынке | Абстракция, возможность быстрого переключения через конфиг | **Низкий** |
| **Kafka / RabbitMQ** | Open Source | Средняя | Средняя | **Низкая** (стабильный open source) | Есть совместимые аналоги | Использование стандартных протоколов, абстракция в коде | **Низкий** |
| **PostgreSQL** | Open Source | Высокая | Высокая | **Низкая** (нет вендора, стандарт SQL, глобальное сообщество) | Совместимые сборки (Postgres Pro) | Отказ от специфичных функций БД в пользу стандартного SQL | **Низкий** |
