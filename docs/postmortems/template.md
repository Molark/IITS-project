# Шаблон разбора инцидента (Blameless Post-Mortem)

 **Принцип:** Мы меняем систему, а не наказываем людей. Ошибка человека — это симптом системной проблемы.

- **Резюме:** (Что случилось, уровень, общая длительность)
- **Влияние:** (Затронутые пользователи, точки, сгоревший бюджет SLO)
- **Хронология:** (По минутам, на основе телеметрии и записей протоколиста)
- **Причины:** (Технические, организационные и способствующие факторы, метод "5 почему")
- **Что сработало хорошо:** (Обнаружение, Runbook, коммуникация)
- **Что сработало плохо:** (Где были задержки, чего не хватило)
- **Действия:** (Конкретные задачи с владельцем и сроком, без задач "поговорить с дежурным")
- **Уроки:** (Что мы поняли о системе, чего не знали раньше)
